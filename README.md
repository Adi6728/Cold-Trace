# ColdChain Trace

ColdChain Trace is a cold-chain pharmaceutical supply-chain traceability platform designed to provide end-to-end visibility for product movement, environmental conditions, and verification workflows.

## Current status

This repository is in Level 0 initialization stage. The foundational structure is in place, but no business features, APIs, data models, authentication, blockchain logic, or IoT implementations have been added yet.

## Repository layout

- backend/ — FastAPI service foundation
- frontend/ — Next.js application foundation
- blockchain/ — Hyperledger Fabric integration area
- iot/ — IoT sensor and edge logic area
- mqtt/ — MQTT messaging and simulation area
- docs/ — architecture, requirements, and design placeholders
- scripts/ — operational and setup scripts
- tests/ — validation and integration test scaffolding

## Prerequisites

- Git
- Python 3
- pip
- Node.js and npm (when available in the environment)
- Docker and Docker Compose (required for future service orchestration)

## Notes

This project intentionally avoids implementation details in the initial stage. Core services and business logic will be added in later milestones.
